# LUMI 앱

AI 연구 비서 **LUMI agent**를 스마트폰(안드로이드·아이폰)과 PC에서 앱처럼 여는 웹 앱(PWA)입니다.

- 열 때마다 연구 저장소의 `remote/` 폴더에서 **가장 높은 버전의 LUMI agent**를 받아 띄워요.
  PC(바탕화면 LUMI)와 휴대폰이 늘 같은 버전이고, LUMI agent를 고치면 모든 기기에 바로 적용돼요.
- 이 저장소는 **공개**예요. 여기에는 앱 첫 화면·아이콘만 있고 **토큰·연구 기록은 없어요.**
  저장소 이름과 토큰은 처음 한 번 입력하면 그 기기의 브라우저(앱)에만 저장돼요. 연구 기록은 계속 비공개 저장소에 있어요.

## 설치
1. 휴대폰 브라우저로 이 저장소의 GitHub Pages 주소를 열어요 (Settings → Pages에 나오는 주소).
2. **아이폰(Safari)**: 공유 버튼(□↑) → **홈 화면에 추가**
   **안드로이드(Chrome)**: 화면의 **📲 앱 설치** 버튼, 또는 ⋮ → **홈 화면에 추가**(앱 설치)
3. 홈 화면의 **LUMI** 아이콘으로 열고, 처음 한 번 저장소 소유자·이름·토큰을 넣어요.

## 파일
| 파일 | 역할 |
|---|---|
| `index.html` | 앱 첫 화면(실행기). 바탕화면 실행기(`install/LUMI.html` ver.2)를 바탕으로 설치 안내·홈 화면 아이콘을 더함 |
| `manifest.webmanifest` | 앱 이름·아이콘·전체 화면 설정 |
| `sw.js` | 앱 첫 화면 파일만 기억해 인터넷이 없을 때 보여 줌(GitHub API·연구 기록은 저장하지 않음) |
| `icons/` | 홈 화면 아이콘 |

LUMI agent 자체가 바뀌면 이 저장소는 고칠 필요가 없어요. 앱 첫 화면(실행기)을 바꿀 때만 `index.html`을 고쳐요.
